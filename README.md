# SillyToken · SillyTavern 用量统计

统计 SillyTavern（酒馆）的 **Token 用量、请求次数与费用**。

和常见的用量统计不同，它能抓到**装在酒馆助手上的插件 / 前端界面**发出的请求 —— 那些脚本跑在
iframe 里，用的是它们自己的 `window.fetch` / `XMLHttpRequest`，普通的 fetch 钩子看不见。

## 与原版的差异（v2.5.0）

### 1. 请求捕获层重写（这是 fork 的主要原因）

原版只在**主窗口**上 patch 一次 `window.fetch`，且只认一个 URL。于是下面这些全部漏掉：

- **酒馆助手的脚本 / 前端界面**跑在无沙盒 iframe 里，有自己的 `fetch` 与 `XMLHttpRequest`
- `jQuery.ajax` / axios 走的是 XHR，根本不经过 `fetch`
- `TavernHelper.generateRaw()` 这类宿主函数，网络层可能不出现 fetch
- TauriTavern 或其它扩展重写 `window.fetch` 时，一次普通赋值就会把捕获层整个丢掉

现在改为**每个同源窗口都装一遍**，对每个窗口装上 `fetch`（属性访问器）/ `XMLHttpRequest` /
`TavernHelper.generateRaw`，并用 500ms 看门狗周期补装。跨层去重保证同一次生成只记一条。

### 2. 修掉一个致命 bug

原版 `recordUsage()` 里的 `cost` 变量声明在 `for` 循环体内、却在循环外使用，
**每次记录都抛 `ReferenceError`**，导致今日统计、历史归档、用量限额、悬浮球角标全部不生效，
`saveSettingsDebounced()` 也从未执行（数据不落盘）。同时修掉了「网络失败时会把同一个请求重发一遍」。

### 3. 统计面板重做

对齐 DeepSeek 开放平台 / New API 的视图：

- 时间范围 **今天 / 近 7 天 / 近 30 天 / 全部**
- 日柱图按**连续日期**铺满（缺日补 0，不会错位），**点柱子看当天按模型明细**（平板没有 hover）
- 概览：消费金额、总 Token、输入 / 输出 / 缓存命中、**缓存命中率**
- 明细：每个模型的费用 / 占比 / Token / 请求数，支持**按模型**或**按厂商**分组

### 4. 费用可追溯重算

原版在**记录当时**就把费用算死。如果一开始没填价格，之后补上也不会回填。

现在每个模型桶都保留 `输入/输出/缓存/请求数`，今日与历史归档也存按模型用量，
于是补上单价后 `累计 / 会话 / 今日 / 历史` 会**全部重算**。

### 5. 模型名匹配

- 归一化：去 `vendor/` 前缀、`_`→`-`、去日期尾巴、去 `:free` / `-preview` 之类的装饰
- 自动推断：`deepseek-flash` 能匹配到价格表里的 `deepseek-v4-flash`
- **手动覆盖**：价格表新增「别名」列，可以自己把外部模型名钉到某一档价格
- **只有请求名不带版本时**才允许跨版本推断 —— `gemini-2.5-flash` 绝不会被并到 `gemini-3.7-flash`
- 界面上会标出每个模型的计价来源（精确 / 别名 / 模糊 / 未设单价）

### 6. 未设单价的模型会弹窗提醒

检测到价格表里没有的模型时弹一次 Toast，面板顶部也有警告条与「一键补入价格表」。
未定价的模型费用记 0，但**会被明确标注出来**，不会静默消失。

### 7. 运行日志

借鉴了 worldbook-manager 的 cache-inspector 做法：定长环形缓冲（400 条）、写入前截断、
暴露全局诊断入口。面板底部有日志区，可**复制日志 / 复制诊断 / 导出 / 清空**。

没有 DevTools 的设备（比如平板）也能自查：面板上那一行
`🛰 已捕获 N · 估算 M · 未捕获 K · 窗口 W` 就是抓取健康度。

### 8. 其它修复

- 历史归档用 `+=` 反复累加当天总额（n 次请求会膨胀成 n(n+1)/2 倍）
- 月预算 / 周额度把今天算了两次；跨夜后把昨天的数当成今天
- 周重置时刻 `12:19` 被 `setMinutes` 解析成 `00:12`
- OpenAI 语义下 `prompt_tokens` 已含 `cached_tokens`，被重复计数 + 重复计费；
  Anthropic 同时有读写时 `cache_read` 被丢掉；DeepSeek 的 `prompt_cache_hit_tokens` 从未被识别
- `Ctrl+Shift+T` 等若干小问题；删掉了从未被调用的 280 行死代码

### 9. 后续版本增量（v2.4.0 / v2.5.0）

- 时间范围扩到 **今天 / 近 7 天 / 本周 / 近 30 天 / 本月 / 全部**，外加自定义起止日期
- 5 套配色主题（横竖屏、平板触屏都验过），文字对比度按 WCAG AA 逐项校验
- **「精确追踪」开关立刻生效**：关掉马上停止记账，打开立刻补装捕获层 ——
  不用再重启酒馆（旧写法只在启动时读一次，勾了没反应）
- **导入数据前二次确认**，并把导入的 JSON 当不可信输入处理（挡掉 `__proto__` 之类字段）
- 修掉一个栈溢出：宿主把 `fetch` 包成「转调我们这一层」时，
  非生成端点的**透传**会绕回自己无限递归；透传现在也走深度保护
- 同一帧内的多次面板重绘合并成一次，历史记录多时点控件不再卡顿

## 安装

1. 酒馆 → **扩展** → **安装扩展** → 粘贴本仓库地址
2. 或者手动：把整个文件夹放到 `public/scripts/extensions/third-party/SillyToken/`
3. 重启酒馆

> ⚠️ **如果你以前装过 TokenFlow，请先删掉它。** 两份捕获层同时存在会让每次请求被记两次。

## 使用

- 右下角**悬浮球**：点击展开统计面板
- 面板顶部切换时间范围与分组维度
- **点柱子**看当天按模型明细，再点一次取消
- 设置面板里可以编辑模型价格、别名、汇率、保留天数（默认 365 天）

## 关于币种

价格表是 **USD 基准**，面板里通过「显示币种 + 汇率」换算成你想看的货币。
DeepSeek 官方报价是 CNY，想让面板和官方平台对得上，把汇率设成当前汇率即可。

## 排障

控制台里有全局入口：

```js
__sillyTokenDiagnostics()   // 每个窗口各层是否装在最外层、抓取计数、未定价模型
__sillyTokenLogs()          // 最近的运行日志
```

面板底部的「复制诊断」会把同样内容复制到剪贴板。
